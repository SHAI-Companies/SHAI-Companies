# Workflow: Crisis Response

**Cadence**: On activation.
**Trigger**: Chris, RDO, or GM reports an incident. Or: Gmail watch picks up urgent inbound.

## Sequence

1. **First 15 minutes** → `operations/crisis-response` produces first-hour response kit
2. **Hour 1–4** → continuous updates, escalation decisions, draft communications
3. **Hour 4–24** → `people/gm-comms-coach` drafts any internal follow-up; `brand/brand-compliance` notifies brand if L2+
4. **Post-incident** → crisis-response produces after-action report

## Human gates
- All external communication requires Chris approval
- L3 incidents trigger immediate legal counsel engagement (human initiates)
- Media inquiries routed to Chris only — agents never speak externally

## Exit criteria
- Incident closed and documented
- After-action recommendations captured and routed to responsible departments
