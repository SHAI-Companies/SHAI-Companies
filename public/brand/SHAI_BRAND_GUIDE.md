# SHAI Corporate Brand Guide

## Body Font
Primary body font: **Inter**.
Recommended stack: `Inter, Inter Display, Arial, sans-serif`.

## Logo / Display Font
Use **Inter Display ExtraBold** as the closest practical corporate system font for the SHAI wordmark. The generated mockup is image-based, so there is no embedded editable font metadata to extract.

## Color Palette
- Navy: `#0B1F3A`
- Pink: `#FF2DB2`
- Blue: `#1A6BFF`
- Slate: `#6B7A90`
- Light: `#F2F4F7`

## Usage
Use the dark primary lockup for executive dashboards and owner-facing report covers. Use the light-background version for documents, email headers, and slide interiors. Use the A monogram for app icons, favicons, avatars, and small placements.
